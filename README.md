# MeroHisab · Merostatus (Nepal Daily Hisab)

**Merostatus (मेरो हिसाब)** is a clean, offline-first personal finance tracker tailored for households, small shopkeepers, students, and daily spenders in Nepal.

- **Developer:** Gita Subedi
- **Publisher:** FlowLabsOfficial
- **Package Name:** `com.flowlabsofficial.merostatus`
- **Default Currency:** NPR (रु.)
- **Bilingual:** English + नेपाली
